# Changelogs

Add one Markdown file per KTFR release, named after its version (for example, `1.0.3.md`).

Recommended sections:

- **Added** — new fixes, integrations, and features.
- **Changed** — behavior changes to existing patches.
- **Fixed** — bugs corrected in KTFR.
- **Compatibility** — supported Minecraft, loader, and target-mod version changes.
- **Testing** — distinguish build verification from in-game confirmation.

Only include changes that actually shipped in that release. Do not retroactively invent release notes for versions whose history has not been verified.
